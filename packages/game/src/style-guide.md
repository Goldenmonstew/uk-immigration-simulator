# 小镇事件文案风格

人物和情节均为虚构。每张卡写一件具体的小事：NHS 候诊室的塑料椅、火车罢工后挤满人的站台、房东的邮件、超市黄标、淋湿的袜子、同事带来的饼干、council tax 信封。先让人看到生活，再看到选择；不要用政策字段替代故事。

标题短一点，中文正文每条不超过 60 字；英文同步表达事实与选择，读起来像日常对话，不逐字硬译。轻松、有一点幽默，笑点落在处境，不落在国籍、职业、家庭结构或任何群体身上。不说教，不写“你应该”，不给人物贴道德分数。

两个或三个选择都要像角色真的会做的事，并写出眼前代价。后果落在角色身上：房东扣了押金，林遥没睡好，同事留下了便当；不写“连续居留属性减一”这样的台词。约一半事件只改变生活属性与叙事。连锁的后一张记得前一张发生了什么，不凭空改变关系或工作。

机制说明只放在选项的 note，一句话说清记录了什么，不预测获批。涉及签证、犯罪或福利时交给引擎显示后果，游戏不另写规则。虚构工资、开支和考试游戏阈值不冒充政策门槛；真实费用从有来源的参数读取。出国行动是归来时回顾的完整旅行，用实际日历日期记离境，不把未来行程算作已发生。事件不免费发放续签，相关手续在签证中心完成。
