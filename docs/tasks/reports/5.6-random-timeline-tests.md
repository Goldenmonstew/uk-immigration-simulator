一个测试文件、一个请求生成器，内置 Mulberry32，无新依赖。固定种子为 `0x56c0ffee + index`，`index = 0..1999`（十进制种子 1455489006–1455491005），生成 **2000** 个请求；每例使用同一个请求分别评估 zh-CN 与 en。

生成范围包括 1950–2010 年出生日期、多个国籍、2026–2040 年模拟日期、0–4 段许可、0–3 段缺席、0–7 个收入年度及 partnerEarnings，以及福利、关系、犯罪、违规与 Article 31。许可从全部 `Route` 中抽取，包含 MAIN / DEPENDANT、相接 / 重叠 / 有空隙的日期，以及按路线填写或省略的全部可选字段；英语、Life in the UK、健康收入豁免、政府债务、settled、asylum support 偿还及保护身份撤销也随机有无。以 30% 概率附带另一条独立生成的 principal 时间线。

规则集选择覆盖缺省、空数组、单栏、全部及倒序全部。逐例检查不抛错、规则集键集合、六态、日期与年限关系、规则 ID 唯一、三态、非空解释、来源字段、assumptions 字符串数组、短路栏不含日期与年限，以及中英文规则 ID 顺序 / 状态 / 结论 / 年限 / 日期一致；同时比较 routeGroup、policyAsOf、来源与 pendingDetails。失败时打印 `JSON.stringify({ seed, request }, null, 2)` 并重新抛出错误。
