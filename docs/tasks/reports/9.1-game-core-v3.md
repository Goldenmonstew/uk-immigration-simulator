## 契约偏离

仅追加两个可选、可序列化字段，原有 v3 名称和字段形状保留：

```ts
interface GameState {
  trip?: { from: IsoDate; to: IsoDate };
}
interface DayState {
  resumeMinute?: number;
}
```

- `trip`：旅行遇到本日或跨季事件时必须暂停并等待客户端选择，需要保存行程起止；否则 JSON 恢复后无法继续跳季或正确写入离境。完成归来或结局后清除。
- `resumeMinute`：步行或长活动跨过来电钟点时，停在准确的电话时间并记住剩余时间终点；`resolve` 后自动推进余下分钟，避免跳到夜里才接中午电话，或因接电话白拿半天行动时间。整段时长完成后清除；客户端不需要额外操作。
- `endQuarter` 保留季末财务与引擎结算职责，只接受第三天且当日/后续日卡片已处理的状态；日常客户端用 `sleep` / `fastForward`，不能用它跳过待送达事件。
- 季度事件使用 `eventQueue` 保存尚未分配的卡，每次醒来以 1/剩余天数的概率分到当日，第三天全分。每张卡最终落在三天的概率相同；这样不再增加第二张多日状态表。
