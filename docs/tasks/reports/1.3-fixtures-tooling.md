## 4. 发现与建议（范围外，不实现）

- **p31 契约缺字段**：`PersonTimeline` / `Relationship` 无法表达主申请人的 qualifying pathway、两人的到达日期关系、或主申请人是否同时满足 settlement 条件。p31 A 保留原文确定的 dependant 五年期望，主申请人满足五年路径的事实只在注释中；在补齐契约前，不能把该 fixture 当作完整的 dependant 语义验收。p31 B 按 brief 只做主申请人，伴侣晚到日期也仅为注释背景。
- **Care worker 证据字段**：`ImmigrationEpisode` 可表达路线、SOC 和薪资，但没有独立的 genuine employment / sponsorship 证据字段。p45 案例将其作为明确假设，不以字段缺失推断 `UNKNOWN`，也不擅自扩展契约。
- **产假字段**：契约只能表达 p16 的收入变化，不能直接标注 maternity leave；best-years 所需的七年收入、其中五年达标已完整提供。
- **既有 fixtures**：原有 C / D 未提供 `lifeInTheUk`。按本任务“C、D 已有，不改”保留原样，切换到真实期望值断言前由负责人复核。
