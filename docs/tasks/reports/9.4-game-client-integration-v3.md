### 组一：`Feat: 小镇接入真实 v3 核心并支持旅行与家人`

- 删除 `apps/web/app/game/mock-core.ts`。
- `apps/web/app/game/{game-client,game-view,life-overlays,town-canvas}.tsx`、`apps/web/app/game/{scene,session}.ts`：生活 API / 类型全部由 `@uk-immigration/game` 导入；营业时间读取 `places.hours`，可做活动使用 `activities`；移除 mock 的 `isOpen`，不调用 `endQuarter`。`resolve` 直接让核心恢复 `resumeMinute`。
- 旅行期间卸载小镇画布，显示起止日期、当前显示日期、继续旅程；处理旅行消息后继续核心流程。通过 `trip` 和新增离境记录识别暂停、直接归来两条路径；只在核心已写入实际离境后显示归来提示。所有新季度日志（包括最后一季和一次旅行跨过多季）都进入小结。
- 家中镇民由 `townsfolk` + `npcAt === 'home'` 选择，按床边、厨房、沙发旁固定点绘制；家里的名单先让玩家走近再聊天，在小镇里不显示这些人。沿用三个家庭 id 的贴图映射，未知 id 使用已有后备贴图。
- 物品、食谱、节日标题、正文、活动及摊位商品直接读取核心数据；未知物品／作物图标回退。菜地交互先进入 allotment；其他生活操作的核心拒绝在 UI 边界显示双语提示，钓鱼拒绝不会显示假成功。
- v3 存档键不变，增加客户端格式标记，忽略 mock 时期同名旧档；允许无 pending 的真实季度事件队列。只在存档读取处验证外部输入。
- `apps/web/i18n/{en,zh-CN}.ts`：旅行与操作反馈文案；`apps/web/test/game-page.test.tsx`：保留原覆盖，迁到真实核心，测试专用事件／家庭数据在用后清理，不 mock 生活 API、不加载 Phaser。

### 组二：`Fix: 隔离操作反馈并限制小镇画布高度`

- `apps/web/app/game/game-client.tsx`、`apps/web/app/game/life-overlays.tsx`、`apps/web/app/game/scene.ts`：反馈由本次成功操作生成一次标记，tick / enter / readMail 不重播旧 outcome；更换或关闭界面清空文字。连续相同操作仍产生新反馈。
- `apps/web/app/game/town-canvas.tsx`、`apps/web/app/game/town-canvas.module.css`：测量画布顶部并监听 HUD / 窗口尺寸变化，高度不超过 640px 与当前可视剩余高度；室内镜头缩放同时考虑高宽。

### 组三：`Feat: 打磨节日氛围好感反馈与逐日小结`

- `apps/web/app/game/scene.ts`：绿地按 festival 绘制摊位和彩旗，春节灯笼、圣诞彩灯、Bonfire Night 傍晚篝火和烟花；18:00 后窗灯及更明显的路灯光晕，保留雨滴、地面压暗、雪和夜色。作物成熟画面按真实生长阈值映射。
- `apps/web/app/game/{game-client,game-view,life-overlays,town-canvas}.tsx`：heart 事件采用对话样式并显示实际心数变化；镜头跟随交谈镇民，在非家庭建筑里的人交谈时显示于门口。聊天、送礼按喜好显示不同气泡，收获、钓鱼成功、升职有飘字／特效；小结明确显示升职提示。
- 场景镇民上限 12；手机天气图元 36、桌面 70，烟花 16；同时反馈对象上限 12，完成或切图后释放。减少动态效果偏好下停止烟花扩散与飘字位移。没有新增无限粒子发射器。
- `apps/web/app/game/diary.ts`（新增）、`apps/web/app/game/session.ts`：客户端另存按天的生活记录和真实季初属性快照，不修改核心日志或规则。小结按第 1／2／3 天分组，重复操作合并计数，物品数量与属性差保留；快进日志依现有核心的 work/class → rest/relax → festival 顺序归组。季初快照使吃饭、聊天、早睡等未写入核心日志的属性变化也计入季度总变化。
- `apps/web/app/game/game.module.css`、`apps/web/i18n/{en,zh-CN}.ts`、`apps/web/public/game/assets/ATTRIBUTION.md`、`apps/web/test/game-page.test.tsx`、本报告：对应界面、双语、来源说明及回归覆盖。
- 检查现有素材及可核验的原始 CC0 图集，未找到适合的鸭、猫或鸽子，按 brief 跳过小动物。新增节日与光照布置使用 Phaser 几何图形，没有引入外部图片。
