# Phase 10.5 规划（2026-11-10）：试玩修复

## 背景

2026-11-06，Fable 在线上站点（uk-immigration-simulator.pages.dev，main 8866f9e）完整试玩了三局林遥，并在 375 宽度下看了陈嘉宁的开局。三局分别是：

- **第一局**：第一季度 3 天全部手动，之后快进。第 2 年逾期出局，中途没有提醒。
- **第二局**：快进加手动续签。第 5 年逾期出局，原因是 Fable 的脚本漏了第二次续签。
- **第三局**：勤快玩法，每季和所有人聊天，按时续签，考英语。第 8 年拿到定居。
  - Life in the UK 5 年都没出现，是 Fable 改存档补上的。

试玩时浏览器面板被限帧，帧是用脚本推进的。因此走路手感、动画流畅度和声音都没有评估。

用户看完试玩评价，选择"派修复任务"。本阶段只修已核实的硬伤和交互摩擦，另补开局引导和初次见面。人物声音、好感剧情、事件密度、经济这类方向性改写不在本阶段，见 §5。

## 2. 契约

不改公开 API 的名字与形状，不加新导出，客户端只用现有导出：`places`（含营业时间）、`activities`、`peopleAt`、`npcAt`、`townsfolk`、`items` 等。

- **季节改动（G1）**会改变陈嘉宁、索菲娅开局显示的"第 N 季"。客户端测试若写死了季号，astra 不要改测试去迁就旧值；合并时由 Fable 处理。
- **新行动（G3）**的 id 为 `life-in-the-uk`，地点为 `college`。客户端不需要专门处理。

- 人物声音重写：9 个人说话是同一种散文式小感慨，台词不回应玩家近况。

- 事件密度：快进时一年 2–3 张事件卡。
- 经济：后期存款数万却无处可花，属性后期接近满值。
- 叙述人称统一："你"与"林遥"混用。
- 户外地点的实物美术（公告栏、村绿地只有标签），以及结局页的视觉。
- 小动物。
