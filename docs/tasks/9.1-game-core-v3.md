## A. 天与时钟

1. `GameState` 改为 v3（§3）：删 `actionsLeft`，加 `dayNumber`、`day`、`inventory`、`friendship`、`plots`、`heard`、`outcome`。
2. 每季三天：`index` 0 工作日、1 周末、2 节日（`kind: 'special'`，`festival` 按 `state.quarter` 的季节选；秋季按 `day.date` 的日历年，奇数年 `bonfire-night`、偶数年 `christmas-market`）。`day.date` 只用于显示与节日：
   - 工作日：`state.date` + 7 天之后的第一个周二。
   - 周末：`state.date` + 30 天之后的第一个周六。
   - 节日：该节日落在本季窗口 [`state.date`, `state.date` + 3 个月) 里的那天，不在窗口里时取窗口内最后一个周六。节日日期规则：春节聚会为二月第一个周六，五月节为五月第一个周一，夏日集市为八月最后一个周六，Bonfire Night 为 11 月 5 日，圣诞集市为 12 月 25 日前的最后一个周六。
3. 时钟：每天 07:00（420）在家醒来；`tick` 与 `doActivity` 推进；到 1440 时自动回家睡觉，心情小降。
4. 天气按季节概率抽（游戏设定），雪只在冬季。
5. `sleep`：先把当天没送达的事件逐个变成 pending（返回后由客户端处理，再调 `sleep`）；都处理完后进入下一天；第三天之后调用 `endQuarter`（v2 的季末逻辑不变），再开下一季第一天。睡得早晚对健康或心情有小影响（游戏设定）。
6. `fastForward`：按默认作息走完剩下的日子并结束这一季，停在下一季第一天早上；遇到 pending 事件立即返回。默认作息只做生活类活动：工作日上班，晚上英语低于 B2 阈值且付得起就上课、否则放松；周末休息加放松；节日去绿地。默认作息不续签、不考试、不出国、不申请定居。

## B. 地点、活动、出国

1. `places`：§1.2 的 16 个地点与营业时间。签证中心与市政厅每天 08:00–20:00；GP 周末关门；公司只在工作日上班。
2. 活动表：`locationActions` 改成 `Activity`（加 `place`、`minutes`、`oncePerDay`），保留 v2 的 id。新增：家里午睡与自学、图书馆自学、咖啡馆咖啡、长椅、公告栏、菜地租地、节日活动。数值按"一天做三四件事"重调，单件比 v2 小，集中写进 `balance.ts` 并注明游戏设定。
3. 续签、申请定居、离开英国的效果与费用不变（`extensionFor`、参数文件）。`exam` 的 B1 / B2 证明逻辑与 `system-exam-failed` 不变。
4. 出国：`travel-1` / `travel-3` / `travel-6` 在车站当天出发，跳过本季余下的日子；行程跨过季末就继续跳季，期间照常季末结算。离境在归来后的第一个季初写入时间线，起止为 `day.date` 起 N 个月的实际日期。任何时刻时间线里都不能有晚于 `state.date` 结束的离境。行程结束日晚于当前签证到期日时该行程不可选。旅费与心情沿用 v2 设定。

## C. 事件送达

   - 电话、短信、消息类：`phone`。
   - 明显发生在某个地点的：`place:<PlaceId>`。
   - 与家人或镇民面对面说话的：可用 `npc:<NpcId>`（对应镇民在 9.3 才写的，先标 `morning`，报告里列出来）。
   - 其余不标，即 `morning`；`system-*` 事件保持 `morning`。
   可以先用脚本粗标再逐张过一遍，脚本不入库。
2. 季初仍按 v2 规则抽 1–2 张，分配到三天中的某一天。`mail` 行动去掉，信件按 `channel` 进信箱。`phone` 在当天 12:00–21:00 的随机钟点送达。没送达的在 `sleep` 时弹出；一季结束前全部处理完。
3. pending 事件期间不能做活动、聊天、送礼、睡觉、快进（同 v2 的行动锁）；市政厅评估仍可看。

   - 茶、饼干、花、蛋糕；本任务那个节日的节日食物；食谱做出的菜。
   价格与心情 / 健康加成是游戏设定。
2. `recipes` 至少 3 个。
3. `shop`：街角小店按季节卖种子与小礼物；节日当天绿地摊位卖节日食物。不实现出售。
4. 菜地：租地后 6 格；`plant` 只接受当季种子；每过一天（含快进的日子）`growth` +1，当天浇水或下雨再 +1；达到 `days` 可收 1–3 个；过季未收的枯掉。
5. `fish`：花 30 分钟；`caught` 为 true 时按季节、天气、钟点抽；false 时只花时间。
6. `cook` 按食谱消耗材料；`eat` 加属性。
