# 任务 8.4：客户端接入真实 v2 核心并打磨（负责：astra；Fable 验收）

## 背景

8.2（含 8.2b / 8.2c 修复）与 8.1 已合并：`apps/web` 的 `/game` 跑在 mock 核心上，`packages/game` v2 提供了真实 API。本任务把客户端切到真实核心、删掉 mock 与试玩横幅，并把玩法打磨到可以给真实用户。sol 并行在做 8.3（角色二、三与平衡），页面只依赖导出的 API，角色数量由数据决定。

## 必读

- `AGENTS.md`；`docs/tasks/phase-8-plan.md` §1–§3；`packages/game/src/index.ts`、`types.ts`、`game.ts`、`locations.ts`、`balance.ts`、`achievements.ts`；`docs/tasks/reports/8.1-game-core-v2.md`（接口注意事项一节，逐条照做）；现有 `apps/web/app/game/**`。

## A. 接入真实核心

- 删除 `mock-core.ts`，所有导入改为 `@uk-immigration/game`；类型以包为准。注意 8.1 报告的约定：`quarter` 1–4 对应冬、春、夏、秋（场景的季节换色与顶栏文案按此，不是春起）；`cost` 是行动点（默认 1，市政厅 0），金钱变化在 `effects`；`eventQueue` / `pendingEvent` 不能被行动或结束季度跳过；续签只对包里 `when` 允许的路线开放；出国动作是"归来时回顾"的记录；`visaMonthsLeft` 与 `progress().percent`（8.3 后为整数，接入时先自行取整）。
- 删除试玩横幅与 "mock" 文案；角色选择列出 `characters`（含 `sprite`）；"继续上次"按角色存档。
- 结局页：`narrative(state)` 的句子、两栏最终结果、`achievements`（已获得与未获得分列）、"在模拟器里打开这条时间线"、再玩一次、换角色。

## B. 打磨

- 签证压力可见：倒计时 ≤ 6 个月变红并在顶栏闪一次；进入签证中心时若可续签，续签按钮置顶并写明费用（来自参数）；倒计时 ≤ 3 个月而未续签时，每季开始弹一条提醒卡（文案由 web 写，不预测结果）。
- 行走：地图上步行偏慢（跨图约 20 秒）——提高步速约 1.6 倍，并让点地点按钮时角色以 2 倍速走；到门口的触发区扩大到门前一格。
- 季末小结增加"这一季发生了什么"的事件回顾与属性变化；年末（第 4 季）小结额外显示两栏进度条变化与"去市政厅看详情"。
- 事件卡：选项按钮下的 `note` 小字；选择后属性变化用 +/− 动画一次（CSS 过渡即可，不加库）。
- 可选音乐：素材包 `musics/` 选一首，默认静音，顶栏一个按钮开关；记入 ATTRIBUTION。
- 手机：375px 下顶栏两行、地图高度 `clamp` 保持、地点按钮横向滚动；全程无横向溢出。
- 性能：`/game` 以外的页面不加载 Phaser（已是）；首次进入 `/game` 显示"正在加载小镇…"直到场景 ready。

## C. 测试

- 用真实核心驱动的覆盖层测试（固定种子）：开局、行动、事件、季末、年末、续签、结局各一例；存档读写；语言切换；英文无中文；任意角色数量。

## 技术约束

- 只改 `apps/web/**`；不改 `packages/game`（接口问题写进报告 §4 让 sol 改）；零外部新依赖；不 push。
