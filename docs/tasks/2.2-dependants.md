## 契约建议（你定稿，Fable 评审）

- `SimulationRequest.principal?: PersonTimeline`：dependant 的请求附带主申请人的**完整时间线**，引擎先评估主申请人（同一个 `simulationDate`，不递归 principal 的 principal），再把其路径年限与结论用于 dependant。没有 `principal` 时行为不变（仍 `INSUFFICIENT_INFORMATION`，解释里说"填写主申请人信息后可判断"）。不要另造"主申请人摘要"输入：用户不知道主申请人的路径年限，那正是引擎要算的。
- `ImmigrationEpisode.dependantOf?: 'PARTNER' | 'PARENT'`：作为谁的 dependant（伴侣 / 子女）。只新增可选字段，不改 `role` 的取值（astra 与 fixtures 在用）。缺省 → 分支未知。
- 参数：`independentAge = 25`（p30）；18 岁沿用 `adultAge`。
- `SettlementAssessment` 不加字段；dependant 的依据写进 `rules[]` 的解释与 `assumptions`。

## 规则（Earned Settlement 栏）

| ID | 判断 | 来源 |
|---|---|---|
| `ES-DEPENDANT-PATHWAY` | 当前 episode 为 DEPENDANT 且有 `principal`：先 `evaluate(principal)`。主申请人该栏 `LIKELY_ELIGIBLE` 或 `LIKELY_NOT_ELIGIBLE` 且有 `earliestDate` → 取其 `pathwayYears` 与 `earliestDate` 作为家庭的定居时点；其余结论 → UNKNOWN（信息不足或主申请人本身未知）。伴侣：与主申请人同一天开始 dependant 居留 → 同时定居；晚于主申请人 → 自己的 dependant 居留起点 + 主申请人的 `pathwayYears`（p29 "complete the same qualifying residence period"）。子女 / 18–24：随家庭，取主申请人时点；25 岁及以上（按模拟日年龄）→ FAIL，解释须独立符合资格或转入自己的路线（p30）。dependant 的 `pathwayYears` = 主申请人的。 | SRC-001 p29–p31 |
| 现有强制规则对 dependant 的适用 | 伴侣与 18–24 岁：criminality、debt、B2、KOL 照常（p29–p30 "adult mandatory requirements"）。18 岁以下子女：豁免 income、debt、英语、KOL，只保留 criminality（p29）。伴侣的收入要求原文只说 "relevant requirements"：按**最低收入要求**（`ES-EARNINGS-10Y` 的个人 £12,571 或家庭 £25,142 口径）处理并在 `assumptions` 声明、登记新 PD；不要对此输出 UNKNOWN（否则 p31 Individual A 无法得到原文的结论）。18–24 岁不需个人收入（p30）。加速路径（3 / 5 年收入、公共服务、British connection）对 dependant 不单独评估，年限跟主申请人。 | SRC-001 p29–p30，p46 |
| 居留 | dependant 的 `ES-RESIDENCE` 按其自己的 DEPENDANT 片段算连续居留（已有逻辑），起点给 `ES-DEPENDANT-PATHWAY` 用。 | SRC-001 p22–p25 |
| 聚合 | DEPENDANT 分支的候选路径 = 强制要求（按上表豁免）+ `ES-DEPENDANT-PATHWAY`；`earliestDate` = max(主申请人时点, 自己起点 + 年限)；`routeGroup` 取主申请人的。短路规则不变（dependant 自己的犯罪记录照常短路）。 | SRC-001 p46 |
