# 任务 2.10：web 收尾——带 locale 调引擎、删手写英文映射、问卷新字段、刷新标题（负责：astra；Fable 验收）

## 目标

2.9 之后引擎能按 `SimulationRequest.locale` 产出英文 `title` / `explanation` / `assumptions` / `shortCircuit.message`，规则元数据有 `titleEn`，变更日志有 `titleEn` / `summaryEn`。本任务让 web 用上它们，删掉过渡期手写的英文映射，并补上 2.5 新契约字段的问卷输入。

## 必读

- `AGENTS.md`；`docs/contracts.md` §9（`immigrationSalaryList`、`settled`）、§10（locale）。
- `docs/tasks/reports/2.5-current-law-completion.md` §4 第 5 条、`docs/tasks/reports/2.9-engine-bilingual.md`。
- `apps/web/i18n/locale.tsx`、`apps/web/lib/questionnaire.ts`（`runSimulation` / `runPrincipalSimulation`）、`apps/web/components/whatif-lab.tsx`、`apps/web/app/policy/page.tsx`、`apps/web/i18n/policy.ts`（将删除）。

## 改动

1. **locale 传给引擎。** `runSimulation(draft, locale)` / `runPrincipalSimulation(draft, locale)` 把当前界面语言放进 `evaluate()` 请求；结果页、What-if、主申请人评估都按当前 locale 计算（引擎很快，切换语言时直接重算；`rememberResult` 若与 locale 不符就重算，取最简单的写法）。前端合成的短路 message 与"主申请人："前缀继续走 i18n key（英文 "Principal applicant: "）。
2. **删除 `apps/web/i18n/policy.ts`。** 政策页英文模式用 `meta.titleEn` 与 `change.titleEn` / `change.summaryEn`；`policy-page.test.tsx` 里对 `englishRuleTitles` 键集的断言改为断言每条规则有 `titleEn`、每条日志有 `titleEn` / `summaryEn`。
3. **问卷新字段。** Skilled Worker 主申请人片段加"担保岗位是否在 Immigration Salary List 上"（是 / 否 / 不确定 → `immigrationSalaryList: true | false | undefined`，带一句说明：不确定按不在清单处理）；主申请人子流程的基本信息步骤加"主申请人是否已定居"（是 → 定居日期 + 定居时所持路线下拉 → `settled: { date, route }`；否 → 不设）。分享链接的结构检查对这两个可选字段放行。
4. **整页刷新时的英文标题。** 已选 English 时整页加载后 `document.title` 仍是中文（Next 的静态 metadata 在 LocaleProvider 的 effect 之后写入）。用最直接可靠的办法修（例如在 `SiteShell` 里按 locale 渲染 `<title>`，React 19 会提升到 head；或在首次挂载后再设一次），用整页刷新验证。

## 技术约束

- 只改 `apps/web/**`；不改 `packages/**`、根配置、锁文件；不 push。零新依赖；zh-CN 与 en 同步补 key；375px 不溢出。
- 测试：locale 透传（`locale: 'en'` 时结果里的规则解释不含中文）、政策页英文模式读 `titleEn`、问卷两个新字段的保存与请求映射、分享往返含新字段。标题修复由 Fable 在浏览器验证。
