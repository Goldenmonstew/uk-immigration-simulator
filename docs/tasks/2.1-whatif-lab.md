# 任务 2.1：What-if 实验室（负责：astra；Fable 验收）

## 目标

在 `apps/web` 加一个页面 `/whatif`：用户改一个输入，立刻看到两栏结论、年限、最早日期怎么变，以及**哪些规则因此翻转、哪些仍未满足**。引擎 `evaluate()` 是纯函数，整件事在前端完成，`packages/**` 一行不改。

## 必读

- `AGENTS.md`（尤其"不要过度工程化"）。
- `docs/tasks/phase-2-plan.md` §2.1。
- `docs/contracts.md` §2（六态）、§7（候选路径与聚合——理解为什么一条规则翻转会改变年限）。
- `apps/web/lib/questionnaire.ts`（`Draft`、`draftReducer` 的 `date` action、`visibleIncomeYears`、`runSimulation`）、`apps/web/lib/storage.ts`、`apps/web/components/result-view.tsx`。

## 页面与交互

1. 入口：结果页 `/result` 的操作区加按钮"情景实验室 · What-if"（i18n key），只在有结果且无 `shortCircuit` 时显示。
2. `/whatif`（`'use client'`，静态导出）：读 `draftStorage().draft`；没有已完成草稿 → 提示并链接到问卷；草稿会前端短路（筛查有"是"）→ 提示实验室不适用于该情景。
3. 基线 = 当前草稿的 `runSimulation()` 结果。页面上方（375px 单列）/ 左侧（≥ 768px 两列）是控件，下方 / 右侧是对比。
4. 控件（每个都是对草稿的一次纯改写，改完立即重算，不写回保存的草稿）：
   - **收入**："最近 N 个 tax year 的个人年收入统一为 X"。N 下拉 1–7（默认 7），X 数字框 + `<input type=range>`（0 到 `earningsThreshold3Year` 的 2 倍，步长 500），三个预设按钮取 `earnedSettlement2026_11.values.earningsThresholdMinimum / earningsThreshold5Year / earningsThreshold3Year` 的 `value`（按钮文字显示金额，不写裸数字）。未启用时收入保持草稿原值（用复选框"启用"）。
   - **模拟日期**：日期框，默认草稿的 `simulationDate`；改日期用 `draftReducer` 的 `date` action，使可见 tax year 跟着变，再应用收入改写。
   - **英语等级**、**Life in the UK**：下拉，默认草稿的值。
   - **假设申请前未领取 public funds**（`benefits: []`）、**假设无缺席**（`absences: []`）：复选框。
   实现为 `apps/web/lib/whatif.ts` 的 `applyWhatIf(draft, whatIf): Draft` 纯函数。
5. 对比展示：
   - 每栏一行"之前 → 之后"：结论（六态文案）、路径所需年限、最早可能日期。
   - 规则 diff（`diffAssessment(before, after)` 纯函数，同在 `lib/whatif.ts`）三组：**翻转为满足**（→ PASS）、**翻转为未满足 / 未知**（PASS → FAIL / UNKNOWN，UNKNOWN → FAIL）、**仍未满足**（之前之后都是 FAIL / UNKNOWN）。每条显示 `title` 与之后的 `explanation`；之后新出现的规则按之后的状态归组。
   - 假设清单用之后的结果，折叠方式同结果页。
   - 没有任何变化时显示"与当前情景相同"。
6. What-if 状态只在内存（刷新回到基线即可），不新增 localStorage key；按钮"重置"回到基线；按钮"返回结果"。

## 技术约束

- 只改 `apps/web/**`；不改 `packages/**`、根配置、锁文件；不 push。
- 零新依赖；CSS Modules；i18n key（zh-CN 必填，en 同步补这页的 key）；无携带用户输入的网络请求。
- 单元测试：`applyWhatIf`（收入改写只动最近 N 年、改日期后 tax year 同步、复选框清空数组）与 `diffAssessment`（三组归类、无变化）；页面无草稿状态的渲染测试。不测引擎本身。
- 不做：保存多个情景、分享链接、图表、拖拽时间线、把改动写回问卷。
