## A. 素材

1. 下载 §2 列出的 CC0 包（OpenGameArt 直链，Fable 已核实脚本可下载）；声音、音乐、特效、表情从 GitHub raw 取 ninja-adventure。只把用到的文件放进 `apps/web/public/game/assets/`，按包分子目录；更新 `ATTRIBUTION.md`（来源 URL、作者、许可、文件清单）；删掉不再用的旧图块。下载与调色脚本不入仓库。
2. 人物：用 RPG Urban Pack 的 6 个角色做玩家与镇民，离线调色派生到能区分 3 个玩家角色、8 位镇民和家人（杰米，陈嘉宁的伴侣与孩子）。和外景放在一起不搭时退回 ninja-adventure 的平民角色，并在报告里说明理由。客户端按 `character.id` / `npc.id` 映射贴图，核心不写素材路径。
3. 作物用 josehzz 包里的 8 种（土豆、草莓、番茄、黄瓜、芜菁、玉米、向日葵、郁金香），每种 5 个阶段。物品图标从这些包里挑，没有的给一个通用图标，未知 id 也用它。
4. 英国味：红色邮筒、公交站牌、酒吧招牌、排屋。没有现成瓦片的，可以对相近瓦片调色。

## B. 地图与场景

1. `public/game/town.json` 约 56×40 格：排屋街（家与邻居）、商业街（小店、咖啡馆、酒吧、GP、图书馆、邮筒、公交站）、办公楼、语言学校、市政厅与签证中心、车站、带池塘与长椅的公园、菜地（6 格加小屋）、村绿地。对象层：`places`（§3 全部 16 个 PlaceId）、`anchors`（16 个 AnchorId）、`plots`、`spawn`、`lamps`。手写或脚本生成都可，脚本不入库。
2. `public/game/home.json`：床、厨房、书桌、门口信箱；从家门进出。
3. 玩家：四向行走，键盘方向键 / WASD，手机点按格子 BFS 寻路（沿用 v2）。走进 building 类地点打开地点菜单；走到 outdoor 类地点出现交互提示（空格 / E / 点按）。
4. 镇民：`townsfolk` 里的每位按 `npcAt` 定位；目标变了就 BFS 走过去；目标是建筑时走到门口消失，离开时从门口出现。`peopleAt` 列在地点菜单里，可以在菜单里聊天。玩家靠近后按交互键或点按镇民 → `talk`。
5. 镜头跟随、地图边界夹紧；保持像素清晰；桌面与手机都能玩。

## C. 一天

1. 时钟：户外每 2 秒现实时间调用一次 `tick(state, 10)`；菜单、对话、事件卡打开时与页面隐藏时停。顶栏显示日期星期、钟点、天气图标。
2. 早晨卡：日期、天气、信箱里几封信、今天是不是节日；关掉后从床边开始。
3. 昼夜：18:00 起暖色，21:00 后蓝色压暗，`lamps` 点亮光晕。天气：雨（粒子、压暗）、雪（粒子）、多云（轻微压暗）。
4. 睡觉：床 → 确认 → 淡出 → `sleep`。第三天睡完显示季末小结：沿用 v2，并加"这一季的日子"（做了什么、和谁聊了、收了什么）。
5. 快进：顶栏"快进这一季"（确认后调 `fastForward`，遇到事件先处理再继续）与"今天到此为止"（回家睡觉）。

## D. 交互界面（React 覆盖层）

1. 对话框：底部，头像、名字、打字机效果，每人一种说话音高。好感剧情与带 `speaker` 的事件用对话框样式，选项在对话框里。
2. 送礼：对话框里"送礼"→ 选背包里的物品 → `gift`。
3. 背包：物品与数量，吃与做饭的入口；旁边一个页签列出镇民与心数。
4. 小店：`shop` 列表、价格、数量、买；节日摊位用同一个界面。
5. 菜地：站在格子上，按状态出现种（选种子）、浇水、收；作物按 `growth` 显示生长阶段。
6. 钓鱼：池塘边抛竿 → 随机 1–4 秒后浮标下沉 → 0.6 秒内按交互键或点按 → `fish(state, true)`，否则 `fish(state, false)`。
7. 信箱：门口信箱显示角标，`readMail` → 事件卡。
8. 飘字与气泡：`outcome` 的 `statDeltas` / `items` 在角色头顶飘出；聊天时冒一个表情气泡。
9. 地点菜单、市政厅两栏、签证中心、事件卡、结局页、角色选择沿用 v2 的组件，改接 v3（`activities` / `doActivity`）；关门的地点显示营业时间。

## E. 声音

脚步、说话哔哔、菜单、金币、成就；每季一首曲子，节日一首。右上角静音键，选择存 `localStorage`；第一次用户手势之后才开始播放。

2. 本任务结束时，`apps/web` 对 `@uk-immigration/game` 只 import `characters` 与数据类型（如 `Character`、`Text`、`StatKey`）；其余全部来自 `mock-core.ts`。原因：9.1 会删掉 v2 的 `act` / `actions` 并改 `GameState`，这样两边能各自合并。进度条可以在 mock 里直接调用引擎的 `evaluate`。
