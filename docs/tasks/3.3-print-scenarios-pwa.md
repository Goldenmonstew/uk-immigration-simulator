# 任务 3.3：结果页打印 / 保存 PDF、本地多情景、PWA 可安装与细节修正（负责：astra；Fable 验收）

## 必读

- `AGENTS.md`；`docs/tasks/phase-3-plan.md` §2 的 3.3。
- `apps/web/app/result/page.tsx`、`components/result-view.tsx`、`lib/storage.ts`、`lib/questionnaire.ts`（`Draft`、`stepSequence`）、`app/layout.tsx`、`components/site-shell.tsx`、`i18n/routes.ts`、`next.config.ts`（保持 `output: 'export'`）。

## A. 打印 / 保存 PDF

- 结果页操作区加按钮"打印或保存为 PDF"（调用 `window.print()`）。`@media print`：两栏改单列；所有 `<details>` 展开（打印前用 `beforeprint` 事件把 `open` 打开，`afterprint` 恢复）；隐藏页头导航、语言切换、按钮、分享区；页首加一行站名、模拟日期、政策核对日期；页尾加免责说明；链接显示文字不显示 URL。

## B. 本地多情景

- 结果页"保存此情景"：输入名称（默认"情景 N"），把当前 `Draft`（含 principal）存入 `localStorage` 的一个数组 key（`uk-immigration-scenarios-v1`：`{ id, name, savedAt, draft }[]`）。
- 首页与结果页列出已保存情景：名称、模拟日期、两栏结论摘要（载入时重算，不存结果）；按钮"载入"（写入当前草稿并进结果页）、"删除"（确认一次）。无网络请求；分享链接照常；What-if 不变。

## C. PWA 可安装

- `apps/web/public/manifest.webmanifest`：name / short_name（中英各一种即可用中文名 + 英文 short_name）、`start_url: '/'`、`display: 'standalone'`、`theme_color` / `background_color` 取现有页头色、icons 192 与 512（PNG：用 SVG 画一个带站名首字母的简洁图标，`qlmanage -t -s 512 -o <dir> icon.svg` 渲染成 PNG 后改名；不加依赖）。`layout.tsx` 加 `<link rel="manifest">`、`<meta name="theme-color">`、`apple-touch-icon`、`apple-mobile-web-app-capable`。
- `apps/web/public/sw.js`：手写最小 service worker——`install` 预缓存 `/`、`/simulate`、`/result`、`/whatif`、`/policy`、manifest；`fetch` 对同源 GET 用"网络优先、失败回退缓存"，并把成功响应写入缓存（含 `_next/static`）；`activate` 清理旧版本缓存（缓存名带构建时间或版本号）。在 `layout.tsx` 的客户端组件里注册（`navigator.serviceWorker.register('/sw.js')`，不可用则忽略）。不做推送、后台同步、更新提示。
- 验证：Lighthouse PWA 可安装项；断网后首页与结果页可打开。

## D. 细节

- 问卷"修改输入"回到最后一步（`restore` 时若 `completed` 则 `step` 取序列最后一步而不是 0），返回按钮仍可逐步回退。
- `routes.ts` 的路线与分组名拆成 `{ 'zh-CN', en }` 两个字段，中文模式显示"中文 · English"（现状），英文模式只显示英文。
- 首页与结果页 `metadata`：description（静态文案）、Open Graph title / description / type；不含用户输入。

## 技术约束

- 只改 `apps/web/**`；不改 `packages/**`、根配置、锁文件；不 push。零新依赖；zh-CN / en 同步补 key；375px 不溢出；无携带输入的网络请求（service worker 只缓存同源 GET）。
- 测试：情景数组的存取与删除、`restore` 回到最后一步、路线名按 locale 显示；打印与 PWA 由 Fable 在浏览器验证。
