# Phase 10 规划（2026-11-06）：补内容

## 背景

Phase 9 上线后，用户选择"继续补内容"。Fable 盘点 main（be02534）的现有内容：

| 类别 | 现状 |
|---|---|
| 镇民（8 位） | 每人 45 句台词；2 / 4 / 6 / 8 心剧情各一张卡，四张合计约 140–170 字 |
| 家人（3 位） | 每人 35 句；家庭时刻只有 2、6 心两段；林遥家里没有人 |
| 小镇卡 `events/town.ts` | 14 张；通用卡里咖啡馆、池塘、长椅、小店、市政厅一张 `place:` 卡都没有 |
| 公告 | 6 条，每季抽 2–3 条，十年里反复出现 |
| 节日 | 5 个，各一段约 25 字的介绍，年年一样 |
| 角色卡 | 林遥 40 张；嘉宁、索菲娅各 80 张 |

9.5 统计一局约 1.0–1.1 万字，但这是按听到的次数计的，重复的台词也算在内，约三分之一的台词是重复的。

判断：要补的是新鲜的东西：
- 每段好感剧情像一小场戏。
- 镇民不总说同样的话。
- 走进每个地方都可能遇到事。
- 公告和节日每年不一样。
- 林遥家里也有人。

## 1. 目标

- **体量**，口径改为"不重复字数"：
  - 积极策略（`balance.test.ts` 的 active）每角色种子 1–20 取平均，一局读到的不重复中文字数 ≥ 15,000。
  - 计入的内容：不重复的台词，触发的事件卡与好感剧情的标题和正文，读到的公告，节日卡。同一段文字只计一次。
  - 台词不重复率 ≥ 80%（不重复句数 / 听到的句数）。
- **好感剧情**：
  - 每段是一小场戏，3–5 段，段与段之间用 `\n` 分隔，合计 80–160 字。
  - 8 位镇民、3 位家人和林遥的室友，2 / 4 / 6 / 8 / 10 心各一段。
  - 现有 38 段改写成这个样子。
- **家人作息（9.5 审查 S5.2）**：工作日要上班的人、要上学的孩子白天不在镇上；失业期间留在镇上。
- **林遥**：加一位室友（家人位），角色卡补到 ≥ 70 张。
- **地点、公告、节日**：
  - 家与签证中心以外，每个地点至少 4 张与角色无关的 `place:` 卡。
  - 公告 ≥ 30 条，分季节。
  - 每个节日 ≥ 3 张节日卡，随年份不同。

## 2. 契约改动

`packages/game` 由 sol 实现，客户端由 astra 接。

```ts
// types.ts
export type NpcLocation = PlaceId | AnchorId | 'away'; // 'away': out of town (work elsewhere, school)
interface Npc {
  schedule: {
    dayKinds?: DayKind[];
    weather?: Weather[];
    festival?: boolean;
    when?: Condition[]; // new: same matching as event conditions, e.g. { flag }
    stops: { from: number; at: NpcLocation }[];
  }[];
}
// game.ts
export function npcAt(state: GameState, npc: string): NpcLocation;
```

- `'away'` 的人不在地图上，`peopleAt()` 不含他们。`townsfolk()` 照旧包括他们，好友列表照常显示。
- `talk` / `gift` 不加位置检查，客户端只给在场的人。
- 新家人 id 为 `yao-flatmate`（`characters: ['skilled-worker']`）。名字与设定由 sol 写，作息和其他家人一样以 `home` 为主。
- 事件正文允许用 `\n` 分段，好感剧情会用到；客户端按段显示。
- 公告加可选字段 `season?: Quarter`；不带 season 的四季都可能贴出。
