## A. 分享链接

- 结果页与 What-if 页加按钮"复制分享链接"：把当前 `Draft`（完整对象）序列化为 JSON → UTF-8 → base64url，放进 `/result#s=<...>`；用 `navigator.clipboard.writeText`，失败时显示链接文本供手动复制。按钮旁一句提示：链接包含你填写的全部信息，只发给你信任的人。
- 打开带 `#s=` 的 `/result`：解析后 `version === 1` 才接受，写入草稿存储并显示结果，页首提示"已载入分享的情景，可修改输入"；解析失败显示普通的"还没有结果"状态。hash 不会发到服务器，仍满足"无携带输入的网络请求"。
- 不做：短链、服务端存储、压缩库、二维码。

## B. en 文案与语言切换

- `apps/web/i18n/en.ts` 补全到与 `zh-CN.ts` 同键集，类型改为 `Record<keyof typeof zhCN, string>`，缺键直接 typecheck 失败。英文措辞沿用现有 en 条目的风格（GOV.UK 式、短句、法律术语原文）。
- 页头加语言切换（中文 / English），选择存 `localStorage`（一个 key），默认 zh-CN；`<html lang>` 跟着变。实现方式自选，最直接的即可（例如 React context 提供 locale，`t` 读 context）；不引入 i18n 库。
- 引擎输出（规则 `title` / `explanation` / `assumptions`、`shortCircuit.message`）在 2.9 之前仍是中文，原样显示，不要在前端翻译它们。路线名 `routes.ts` 维持"中文 · English"双语。
