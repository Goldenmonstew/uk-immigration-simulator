## A. 登记并提取 Appendix Immigration Salary List（SRC-019）

- 抓取 `https://www.gov.uk/guidance/immigration-rules/immigration-rules-appendix-immigration-salary-list` 的 HTML 到 `policy-sources/<版本日期>-immigration-rules-appendix-immigration-salary-list.html`；版本日期取该 Appendix 自己的变更记录最近一条（Content API `public_updated_at` 为 2025-11-11，核实后用），不是手册头部日期。SOURCES.md 表末尾加 SRC-019（LAW），文件末尾加"SRC-019 常用定位"（ISL 段落号、表的列含义）。
- 页面只有一张表（26 行），列为"SOC 2020 occupation code and any further criteria"、"Included on the Immigration Salary List in:"、"Removal date"。新脚本 `scripts/extract-immigration-salary-list.mjs` 生成 `src/data/immigration-salary-list.ts`，导出：

```ts
export interface ImmigrationSalaryListEntry {
  socCode: string;      // 4 位 SOC 2020
  title: string;        // 代码后的职业名（到第一个限制说明为止）
  /** 原表同单元格里的进一步条件（"only …"、"Jobs with a working location in …" 等），原样保留，不解释；没有则省略 */
  criteria?: string;
  /** "Included on the Immigration Salary List in:" 列原文，如 'England, Scotland, Wales and Northern Ireland' */
  nations: string;
  /** "Removal date" 列原文；没有则省略 */
  removalDate?: string;
}
export const immigrationSalaryListOccupations: { source: SourceRef; entries: ImmigrationSalaryListEntry[] };
```

- 从 `src/index.ts` 导出。测试 `test/immigration-salary-list.test.ts`：行数与快照一致、`socCode` 四位数字、抽查 3 行与快照一致（含一条带 criteria 的）。同一 SOC 可能多行（不同限制），不去重。
