# 任务 9.4：小镇客户端接入真实 v3 核心与打磨（负责：astra；Fable 验收）

## 背景

9.1（sol 的 game v3 核心）与 9.2（你的客户端，mock）已合并到本地集成分支 `phase-9`。Fable 在浏览器里走查了桌面与 375px，以下都正常：早晨卡、时钟走与停、室内外地图、镇民作息与进出建筑、聊天与送礼、小店、菜地、钓鱼成败、电话事件的对话样式、夜色与雪、睡前送达、快进与季末小结、刷新后继续、英文界面无中文、首页不加载 Phaser。

走查中发现地图图层缺 Tiled 的 `x` / `y` / `opacity` / `visible` 字段，Phaser 把图层坐标算成 NaN，整张地图一块图块都不画；Fable 已在 `phase-9` 上补了字段（c4a066f）。sol 在并行做 9.3（其余镇民、家人、节日、公告栏、平衡），只加数据，API 形状不变。

## 必读

- `AGENTS.md`；`docs/tasks/phase-9-plan.md`；`docs/tasks/reports/9.1-game-core-v3.md`（"契约偏离"与"给 astra 的数据清单"）；`docs/tasks/reports/9.2-game-client-v3.md`（你列的 mock 差异）。
- `packages/game/src/types.ts`、`packages/game/src/index.ts`（真实 API）。

## A. 接入真实核心

1. 删除 `mock-core.ts`，生活 API 与类型全部从 `@uk-immigration/game` 导入。按 9.1 报告的约定处理：
   - 营业时间读 `places` 的 `hours`，删掉 mock 的 `isOpen`；活动能不能做以 `activities` 的返回为准（真实核心会按剩余时间过滤）。
   - `GameState.trip` 存在时是出国期间：显示一个"在国外"的过场（日期推进、归来提示），用 `fastForward` 或 `sleep` 继续，不画小镇行走。
   - `DayState.resumeMinute` 由核心处理，客户端照常 `resolve`。
   - 不调用 `endQuarter`；`sleep` / `fastForward` 之后出现新的季度日志时显示季末小结。
   - 聊天、送礼的距离判断仍在客户端（核心只知道 PlaceId）。
2. 家人：`townsfolk` 里 `npcAt` 为 `home` 的人画在家里地图的固定点（床边、厨房、沙发），可以聊天；在小镇里不显示。贴图映射已有 `jamie`、`ka-ning-partner`、`ka-ning-child`（9.3 才加这三位，你这边按 id 通用处理即可）。
3. 物品、食谱、节日按真实数据显示；9.3 新增的物品与节日活动不改代码就能显示（按 id 映射，缺图标用通用图标）。
4. 存档仍用 v3 键；mock 时期写的存档形状不同，读不出就当没有存档（存档是系统边界，在读取处判断一次即可）。

## B. 走查发现的问题（必修）

1. 上一次操作的反馈文字（`outcome.text`）会出现在之后打开的无关菜单里，例如送礼的反应出现在小店菜单里。改成只在产生它的界面显示一次。
2. 1000×700 的窗口里，顶栏加 640px 高的画布超出一屏，角色常在屏幕下方，要滚动才看得到。画布高度按可视高度收（例如 `min(640px, 100dvh − 顶栏)`），角色始终在可见范围内。
3. 地点菜单打开时盖住了顶栏的地点按钮，点地点按钮会点到菜单里的购买键。菜单打开时地点按钮不可点，或者菜单不覆盖它们。
4. 以后重新生成地图时，图层保留 Tiled 的 `x` / `y` / `opacity` / `visible` 字段。

## C. 打磨

1. 节日：绿地按 `day.festival` 布置（摊位、彩旗；春节灯笼、Bonfire Night 篝火与烟花特效、圣诞集市彩灯），加上节日活动的界面。
2. 好感剧情：带 `heart` 的事件用对话样式，镜头移到该镇民身上，显示心数变化。
3. 表情气泡与飘字：聊天、送礼（按喜好用不同的气泡）、收获、钓到鱼、升职。
4. 小动物：池塘里的鸭子、街上的猫或鸽子。有 CC0 素材才加，来源写进 `ATTRIBUTION.md`；没有就跳过，在报告里说明。
5. 夜晚：路灯光晕要看得出来，排屋窗户 18:00 后亮起。雨天：雨滴、地面压暗。
6. 季末小结的"这一季的日子"按天分组（第 1 天 / 第 2 天 / 第 3 天），重复项合并计数。
7. 性能：手机上保持流畅（镇民不超过 12 个，粒子数有上限）；375px 不溢出。
