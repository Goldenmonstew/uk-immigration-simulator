## 目标

按 `docs/tasks/phase-8-plan.md` §1 的玩法与 §3 的契约重写 `packages/game`：属性、季度回合、地点行动、带条件与连锁的事件系统、签证压力、结局与成就、结局叙事，以及先把系统跑通所需的内容（林遥 40 条事件、公共 60 条）。v1 的卡牌内容可以改写成事件，不保留 v1 的 API。纯逻辑、无 React、无 IO；后果只由引擎算；不过度工程化。

## 必读

## A. 来源与参数（先做，单独 commit）

- 登记 SRC-030：GOV.UK "Skilled Worker visa: How much it costs"（https://www.gov.uk/skilled-worker-visa/how-much-it-costs ）整页快照 + sha256 + 常用定位（境内申请费、IHS 每年金额、所依据的更新日期）；若该页没有定居（ILR）申请费，再登记 GOV.UK "Visa fees" 费用表页作为 SRC-031。做法同 5.1。
- `packages/policy-data/src/parameters/current-law-2026-11.ts` 加费用参数（名称自定，如 `skilledWorkerExtensionFeeInUk`、`immigrationHealthSurchargePerYear`、`settlementApplicationFee`），每个值带 SRC 定位。游戏只读这些参数，不写裸数字。
- `apps/web/lib/sources.ts` 不归你改，astra 在 8.2 加行；报告里提醒。

## B. schema 与逻辑（`src/types.ts`、`src/game.ts`、`src/locations.ts`、`src/index.ts`）

- 按 §3 实现全部类型与函数：`newGame`、`actions`、`act`、`currentEvent`、`resolve`、`endQuarter`、`progress`、`isOver`、`narrative`、`visaMonthsLeft`，导出 `characters`、`locations`、`achievements`。字段名以 §3 为准，细节自定但写进类型注释。
- 地点行动表（全局，`src/locations.ts`）：家（休息：心情 +、健康 +；收信：触发一个事件）、公司（上班：钱 +、事业 +；加班：钱 ++、心情 −、健康 −）、语言学校（上课：英语 +，花钱；考试：英语 ≥ 阈值时写入 B1 / B2 证明，否则失败事件）、GP（看病：健康 +）、酒吧与公园（放松：心情 +，花钱）、市政厅（只读，不消耗行动点）、签证中心（续签：当前片段剩余 ≤ 12 个月时可用，扣费用参数 + IHS × 年数，写入相接的新片段；申请定居：任一栏 `LIKELY_ELIGIBLE` 时可用，扣定居费，结局 `settled`；换路线留给 8.3）、火车站 / 机场（出国 1 / 3 / 6 个月：离境 + 心情 +；离开英国：结局 `left`）。
- 季度结算（`endQuarter`）：钱 += 当前片段年薪 / 4 − 生活开销；属性自然回落（心情 −、健康按生活方式）；年薪与 `salary` 同步（事业每到阈值升职一次 → `salary` × 1.1 并写入 `incomeYears`）；签证到期检查（到期且未续签 → `immigrationBreaches` 加逾期 → 引擎短路 → 结局 `overstayed`）；抽下一季事件（1–2 个，按权重、季节、条件、一次性、旗标）；年末成就判定；引擎重算 `result`。
- 游戏参数（生活开销、属性回落速率、升职阈值、英语考试阈值）集中在 `src/balance.ts`，注释写明"游戏设定，不是政策数字"。
- 结局：`settled`、`left`、`overstayed`、`criminal`（引擎 CRIMINALITY 短路）、`timeout`（10 年到期）。`narrative(state)` 按 `log` 生成 8–12 句"你的十年"（每类事件一句模板，中英）。
- 成就框架（`src/achievements.ts`，至少 8 枚可判定：五年零缺席、差一天、英语 B2、十年老兵、存款过万、从不加班、搬过三次家……）。

## C. 内容与风格指南（`src/style-guide.md`、`src/events/common.ts`、`src/characters/skilled-worker.ts`）

- 先写 `src/style-guide.md`（中文，半页）：具体、英国生活细节（NHS 排队、火车罢工、房东、超市、雨、同事、council tax）、轻松有幽默、不说教、不写"你应该"、中文不超过 60 字、英文同步、后果写在角色身上、机制说明一句放 `note`、虚构、无群体刻板印象。
- 公共事件 60 条（至少 20 条带连锁、10 条一次性、各季节都有）；林遥 40 条专属事件（含签证续签前后、跳槽、伴侣、父母、酒驾、升职）。约一半事件只动属性与叙事。
- 角色一林遥沿用 v1 的设定与起始时间线；`sprite` 字段指向素材包里的角色文件名（如 `characters/3.png`），astra 按此加载。

## D. 测试

- schema 自检：所有事件 / 行动的效果字段合法，`requires` / `sets` 的旗标互相对得上，权重 > 0，中英都有。
- 20 个种子各跑完整 40 季（随机选行动与选择）：不抛错、属性在 0–100（钱可负）、同种子两次结果深相等、至少出现 `settled`、`left`、`overstayed`、`timeout` 四种结局之一的样本（分别构造用例保证四种都可达）、`progress` 的百分比在 0–100、`narrative` 非空。
- 行动与事件的 Before → Action → After：上班涨钱与事业、考试写入 B2、续签写入新片段并扣费、出国 6 个月写入离境且进度条倒退、逾期 → `overstayed`。
- 运行时间 < 30 秒。
