## 目标

让结果"可行动"：每栏结论下方列出"还差什么"，并能一键跳到 What-if 预填对应控件。纯 UI 聚合，不改引擎输出，不加依赖。

- `apps/web/components/result-view.tsx`（两栏、`rules[]` 分组渲染）、`app/whatif/page.tsx` 与 `components/whatif-lab.tsx`（现有控件：模拟日期、收入改写、英语等级、Life in the UK、public funds 开关、无缺席开关；`initialWhatIf`）、`lib/whatif.ts`、`lib/questionnaire.ts`、`i18n/{zh-CN,en}.ts`、`app/result/result.module.css`（打印样式）。

## A. 差距摘要

- 每栏在结论块下方加一段"还差什么 / What is missing"：
  - `LIKELY_ELIGIBLE`：一句"已满足全部已建模要求"。
  - `LIKELY_NOT_ELIGIBLE` 且有 `earliestDate`：首行"按当前情况最早 {date}，距模拟日还有 {n} 年 {m} 个月"（用 `pathwayYears` 与 `earliestDate` 算）；其后列出 `FAIL` 的规则各一行：规则标题 + 解释的第一句。
  - `LIKELY_NOT_ELIGIBLE` 无日期、`POTENTIALLY_ELIGIBLE`、`INSUFFICIENT_INFORMATION`：列出 `FAIL` 与 `UNKNOWN` 的规则各一行（`UNKNOWN` 带 PD 的标"待政府明确"，不带的标"补填信息"）。
  - `REQUIRES_REGULATED_REVIEW`：不显示摘要（短路页已有说明）。
- 行数超过 5 条折叠"更多"；中英；打印时显示摘要；375px 不溢出。

## B. "去 What-if 试试"

- 对能映射到 What-if 控件的规则，在该行加按钮：英语规则（`ES-ENGLISH-B2`、`CL-ENGLISH`）→ 英语等级；收入规则（`ES-EARNINGS-*`、`ES-PROTECTION-CONTRIBUTION`、`CL-FAMILY-FINANCIAL`）→ 收入改写；`ES-PUBLIC-FUNDS` → public funds 开关；居留 / 年限类（`ES-RESIDENCE`、`CL-*-RESIDENCE*`、`ES-PROTECTION-PATHWAY`）→ 模拟日期；`ES-KOL` / `CL-KOL` → Life in the UK。无映射的规则不加按钮。
- 跳转为 `/whatif?focus=<控件键>`：What-if 页读取 `focus`，把对应控件滚动到视野并聚焦（英语 → 预选当前等级的下一级或 B2；收入 → 启用收入改写并预填门槛值；日期 → 预填 `earliestDate`；其余只聚焦），刷新后 `focus` 不再生效（用后清除）。URL 里只有控件键，不带任何输入。
