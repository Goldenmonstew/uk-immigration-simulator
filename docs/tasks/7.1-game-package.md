# 任务 7.1：`packages/game`——内容 schema、纯逻辑、角色一与运气牌（负责：sol；Fable 验收）

## 目标

为 Immigration Life 教学游戏建一个新 package：游戏内容（角色、选择卡、运气牌）与纯逻辑（开局、抽牌、结算、推进、找出变化的规则），不含任何 UI。后果只由现有引擎 `evaluate` 算出，游戏不写规则。玩法已定案，见 `docs/tasks/phase-7-plan.md` §2 的 7.1 与 §4。不过度工程化：零外部依赖、无 IO、够用就行。

## 必读

- `AGENTS.md`；`docs/tasks/phase-7-plan.md`（§2 的 7.1、§4）；`packages/engine/src/types.ts`（`SimulationRequest`、`PersonTimeline`、`ImmigrationEpisode`、`Absence`、`IncomeYear`、`BenefitEpisode`、`Relationship`、`CriminalEvent`、`ImmigrationBreach`、`EnglishEvidence`、`SimulationResult`）；`packages/engine/src/index.ts`（导出的 `evaluate`、`RULE_SETS`）；`packages/policy-data/package.json`、`tsconfig.json`、`tsconfig.build.json`（照抄最小配置）；`packages/engine/test/random.test.ts`（mulberry32 与请求生成的写法）；`packages/policy-data/fixtures/`（Skilled Worker 的起始时间线可从 `p31-principal.ts`、`es-p31-*.ts` 改编）；`packages/policy-data/src/data/display-names.ts`（路线与枚举的显示名，文案里的术语保持一致）。

## 要做的

### A. 脚手架

- `packages/game/`：`package.json`（`@uk-immigration/game`，`private`，`type: module`，`exports: { ".": "./src/index.ts" }`，scripts 与 policy-data 相同：build / test / lint / typecheck）；`tsconfig.json`（extends `../../tsconfig.base.json`，include `src`、`test`）；`tsconfig.build.json`；依赖只有 workspace 的 `@uk-immigration/engine` 与 `@uk-immigration/policy-data`。新 package 后跑一次 `pnpm install` 让 `pnpm-lock.yaml` 收录它（CI 用 `--frozen-lockfile`），锁文件的改动列进 commit 清单。
- 不加 README、不加脚本、不加配置项。

### B. 内容 schema（`src/types.ts`）

- `Text = { zhCN: string; en: string }`。
- `Character { id: string; name: Text; intro: Text; startDate: IsoDate; timeline: PersonTimeline; script: ChoiceCard[]; luckPool: LuckCard[] }`。`timeline` 是开始日当天的完整时间线（含到开始日为止的片段，当前片段的 `validTo` 至少覆盖到开始日之后），`script` 按回合一张。
- `ChoiceCard { id; kind: 'choice'; title: Text; text: Text; choices: Choice[] }`（2–3 个选择）；`LuckCard { id; kind: 'luck'; title: Text; text: Text; choices: [Choice] }`（唯一选择的 label 为"知道了 / Noted"）。
- `Choice { id; label: Text; effects: Effect[]; note?: Text }`——`note` 一句话说明"这张卡在规则里对应什么"（如"连续离境超过 180 天影响连续居留"），不下结论、不写"你应该"。
- `Effect`（闭合联合类型，只用引擎读取的字段）：
  - `{ type: 'absence'; startOffsetDays: number; days: number }`——自当前游戏日期起的一段离境；
  - `{ type: 'income'; taxYear: 'current' | 'next'; earnings?: number; partnerEarnings?: number }`——写入对应 tax year（用 `packages/engine` 的 `taxYearsBefore` 或自算），已有则覆盖；
  - `{ type: 'episode'; patch: Partial<Omit<ImmigrationEpisode, 'validFrom'>> }`——修改当前片段；
  - `{ type: 'newEpisode'; episode: Omit<ImmigrationEpisode, 'validFrom' | 'validTo'>; durationMonths: number; gapDays?: number }`——把当前片段截到当前日期前一天（有 `gapDays` 则留空档），自当前日期（加空档）起新片段；
  - `{ type: 'benefit'; benefit: Omit<BenefitEpisode, 'from' | 'to'>; startOffsetDays: number; months?: number }`；
  - `{ type: 'relationship'; add?: Relationship; remove?: Relationship['type'] }`；
  - `{ type: 'english'; cefrLevel: EnglishEvidence['cefrLevel'] }`；`{ type: 'lifeInTheUk' }`（置 `{ passed: true }`）；
  - `{ type: 'breach'; breach: Omit<ImmigrationBreach, 'date'>; offsetDays?: number }`；`{ type: 'criminal'; event: Omit<CriminalEvent, 'date'>; offsetDays?: number }`（字段名以 `types.ts` 为准）；
  - `{ type: 'timeline'; patch: Pick<PersonTimeline, 'cashSavings' | 'partnerSpecifiedBenefit' | 'governmentDebt'> }`；
  - `{ type: 'none' }`。

### C. 纯逻辑（`src/game.ts`，无 React、无 IO、可 JSON 序列化）

- 常量：`TURNS = 10`、`TURN_MONTHS = 12`、`LUCK_CHANCE = 0.5`。
- `GameState { characterId; seed; turn; simulationDate; timeline; phase: 'luck' | 'choice' | 'ended'; pendingLuck?: cardId; drawnLuck: cardId[]; log: Array<{ turn; cardId; choiceId; before: SimulationResult; after: SimulationResult }>; result: SimulationResult }`（`result` 为当前时间线的两栏结果；`before` / `after` 只存该步前后的结果）。
- `startGame(characterId, seed, locale)`、`currentCard(state)`、`choose(state, choiceId)`（应用 effects → `evaluate({ simulationDate, timeline, locale })` → 记日志；运气牌与选择卡同一函数）、`advance(state)`（回合结束推进 12 个月，按种子决定下一回合是否抽运气牌并从公共池 + 角色池里抽一张未抽过的）、`isOver(state)`（10 回合结束，或任一栏 `REQUIRES_REGULATED_REVIEW` 短路）、`changedRules(before, after, ruleSetId)`（该栏状态变化的规则 ID 与前后状态）、`characters`（导出全部角色）。伪随机 mulberry32，同种子同序列。
- 只评估主申请人，不传 `principal`；默认两个规则集；`locale` 透传。

### D. 公共运气牌（`src/cards/luck.ts`，至少 8 张，好坏中性都有）

- 例：父母病重回国 4 个月（absence 120 天）；公司加薪 10%（income）；房东涨租（none）；在英国住院 6 周（none，`note` 说明在英国生病不算离境）；意外退税（none）；伴侣找到工作（partnerEarnings）；护照续签延误（none）；收到交通罚单（none，`note` 说明民事罚款不是犯罪记录，引擎也未建模）。

### E. 角色一：Skilled Worker（`src/characters/skilled-worker.ts`）

- 姓名国籍虚构（不要用真实公众人物）；2024 年初持 Skilled Worker 入境的软件开发者，年薪约 £38,000，单身；起始时间线从 fixture 改编，`startDate` 为入境约一年后。
- 10 张选择卡，候选事件：外派 8 个月 vs 留下；跳槽到 £55,000 但岗位与 SOC 变；伴侣来英（关系 + 伴侣收入，游戏不评估 dependant）；伴侣失业后申领 Universal Credit vs 借钱；2027-03-26 前考 B2 vs 等；担保方裁员后 60 天内找到新担保 vs 回国 3 个月；一次酒驾（criminal → 短路，结局提前）；买房（none）；考 Life in the UK；主动降薪换四天工作制。每张卡先确认引擎确实读取所用字段（看 `packages/engine/src/rules/*.ts` 里的 `ctx.timeline.*`），不确定的不写。
- 文案 zh-CN / en：轻松但不戏谑，不对任何群体做刻板印象，不写"你应该……"。

### F. 测试（`test/`）

- schema 自检：每个角色每张卡每个选择，在该回合的基线上应用后 `evaluate` 不抛错、两栏结论属六态；运气牌池无重复 ID。
- 10 个种子各跑一整局（每回合选第一个选择）：不抛错、同种子两次结果深相等、`log` 长度合理、结局触发。
- `changedRules`：对"外派 8 个月"这张卡断言现行法律栏的居留规则状态变化；对"酒驾"断言两栏短路。
