## A. 页面与流程（`apps/web/app/game/`）

- `/game`（静态导出）。页首固定一行提示（中英）："教学游戏：角色与事件均为虚构，结果按今天登记的规则推演，不是建议。"
- **角色选择**：列出 `characters`（名字、简介）；选一个 → `startGame(id, seed, locale)`，`seed` 用 `Date.now() % 2**31`；也可"再玩一次（换运气）"= 同角色新种子。
- **回合**：顶部显示回合数 / 共 10 回合与当前游戏日期。`currentCard` 为运气牌时先显示运气牌（标题、正文、唯一按钮"知道了"）；再显示选择卡（标题、正文、2–3 个选项按钮）。选项 `note` 作为按钮下方的小字说明。点选后调用 `choose`，显示本步结果；之后"下一年"按钮调用 `advance`。
- **两栏并排**（每一步都显示，`displayedRuleSets` 的两栏）：每栏显示结论徽章（复用结果页的文案与样式）、路径年限、最早可能日期；栏下"这一步改变了什么"：用 `changedRules(before, after, ruleSetId)` 列出状态变化的规则（标题、前 → 后状态、可展开看解释与来源），没有变化就写"这一步没有改变这一栏"。短路栏（`REQUIRES_REGULATED_REVIEW`）显示短路文案。窄屏下两栏堆叠，复用 7.2 的栏跳转。
- **结局**：`isOver` 为真时显示结局页：两栏最终结论、年限、日期；"这一局改变最多的三条规则"（按 `log` 里 `changedRules` 的出现次数统计）；按钮"在模拟器里打开这条时间线"（用 `createDraft()` 加 `timeline`、`simulationDate`、`completed: true`、筛查按时间线推（有犯罪记录 → criminality 'yes'，有非法入境 → breach 'yes'）生成 `encodeDraft` 的分享链接跳到 `/result`）、"再玩一次（换运气）"、"换角色"。
- **进度**：`GameState` 存 `localStorage` 的 `uk-immigration-game-v1`（整份 JSON）；刷新后从保存的状态继续；"换角色"清除。存储不可用时仍能玩，只是不保存。
- **语言**：卡片文字按 UI 语言取 `zhCN` / `en`；两栏文字按 UI 语言——切换语言时把 `state.locale` 改为当前语言并用引擎 `evaluate({ simulationDate, timeline, locale })` 重算当前显示的结果（逻辑状态不变）。
- **首页入口**：`home-content.tsx` 的"开始模拟"旁加次级按钮"玩一局 · Immigration Life"（中英），链接 `/game`。
- 不做：分数、排行榜、账号、动画库、服务端、新依赖。
