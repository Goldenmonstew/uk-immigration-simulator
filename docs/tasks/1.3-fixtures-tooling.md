# 任务 1.3：官方案例 fixtures、来源一致性测试与禁裸数字 lint（负责：sol；Fable 验收）

## 目标

给规则引擎准备独立的验收用例和两道机械检查：

1. 把官方回应文件里的示例个案转成 fixtures。Opus 并行实现规则，不会读你的期望值；你的期望值只来自原文，这就是独立性所在。
2. 一个测试：`packages/policy-data` 与 fixtures 里出现的每个 `SourceRef.srcId` 都存在于 `docs/SOURCES.md`。
3. ESLint：禁止 `packages/engine/src` 出现 ≥ 1000 的数字字面量，以及 `Date.now()` 和无参 `new Date()`。

## 必读

`AGENTS.md`；`docs/contracts.md` §5（fixture 写法）；`packages/policy-data/fixtures/es-individual-c-combined-income.ts`（样板）；`docs/SOURCES.md`；SRC-001 在 `policy-sources/`（页码按物理页，用 `pdftotext -f N -l N`，封面为 p1）。

## 1. fixtures

原文案例（物理页）：p19 Individual A（social worker，收入低于 £50,271，走公共服务 5 年）、Individual B（British citizen 的配偶）；C、D 已有，不改；p31 "Dependants: In Practice" 的 Individual A / B（伴侣同时到 / 后到）；p45 "Transitional Arrangements: In Practice" 的 Individual A / B / C（care worker）；p16 产假例子（10 年路径 7 年中 5 年）。难民案例（p40）不做。

每个案例一个文件，命名 `es-p<页>-<slug>.ts`，在 `fixtures/index.ts` 登记。要求：

- `expected` 只写原文能确定的：`outcome`、`pathwayYears`（原文明确给出年限时）、`mustFail` / `mustUnknown`。规则 ID 固定清单：`ES-CRIMINALITY`、`ES-DEBT`、`ES-ENGLISH-B2`、`ES-KOL`、`ES-ROUTE-GROUP`、`ES-RESIDENCE`、`ES-EARNINGS-3Y`、`ES-EARNINGS-5Y`、`ES-EARNINGS-10Y`、`ES-BRITISH-CONNECTION`、`ES-PUBLIC-FUNDS`、`ES-BREACH`、`ES-TRANSITIONAL-CARE-WORKER`、`ES-PUBLIC-SERVICE`；`CL-SCOPE`、`CL-SW-RESIDENCE-5Y`、`CL-SW-SALARY`、`CL-ENGLISH`、`CL-KOL`、`CL-LR-RESIDENCE-10Y`。
- 为落成时间线补的事实（日期、路线、socCode、收入数字）写在文件头注释，并保持"除被测条件外其余都满足"：英语 B2、`lifeInTheUk: { passed: true }`、无犯罪 / 违规 / 债务、无 public funds、居留年限足够。
- SOC 2020：care worker 用 `6135`，social worker 用 `2461`。伴侣后到的案例只做主申请人视角，注释说明。
- 不改 fixture 以外的任何 engine / policy-data 文件；契约缺字段的写进报告。

## 2. 来源一致性测试

`packages/policy-data/test/sources.test.ts`：用 Node 内置 `fs` 读 `docs/SOURCES.md` 的一级来源表取全部 `SRC-xxx`；递归遍历 `packages/policy-data/src/index.ts` 与 `fixtures/index.ts` 导出的对象，收集所有形如 `{ srcId, locator }` 的对象，断言 `srcId` 在表中、`locator` 非空。不引入依赖。

## 3. lint

在根 `eslint.config.mjs` 加一个只作用于 `packages/engine/src/**/*.ts` 的块，用 `no-restricted-syntax`：

- `Literal[value>=1000]` 报错，message 指向 `packages/policy-data` 的参数文件；
- `CallExpression[callee.object.name='Date'][callee.property.name='now']` 与 `NewExpression[callee.name='Date'][arguments.length=0]` 报错。

不装插件。确认 `packages/policy-data/src/parameters` 与测试文件不受影响。

## 不要做

不写规则、不改 engine、不改 parameters / routes、不碰 `apps/web`、不改 CI（现有 `pnpm test` 已覆盖新测试）、不加依赖、不 push。

## 验收（Fable）

- `pnpm lint && pnpm typecheck && pnpm test` 全过（新 fixture 在 stub 阶段只检查形状）。
- 抽查 3 个 fixture 的期望值与原文对照。
- 在 `packages/engine/src` 临时放一个 `const x = 50271` 验证 lint 报错（你自己验证后删除，报告里写结果）。
