# 任务 5.4：现行法律栏的 dependant——HK BN(O)、Global Talent、家庭伴侣的子女（负责：Opus；Fable 验收）

## 背景

5.2 已合并（main 2110c40 起）。现行法律栏对 Skilled Worker 的 dependant 已建模（2.2 / 2.5：`CL-SW-PARTNER-5Y`、`CL-SW-CHILD`，经 `principal` 机制），但 HK BN(O)、Global Talent、Appendix FM 伴侣路线的 dependant 仍由 `CL-SCOPE` 给 `UNKNOWN`（"信息不足"）。本任务把这三组 dependant 补进现行法律栏。Earned Settlement 栏不动。

契约先行：第一个 commit 只改 `docs/contracts.md`（新增 §15）与 `docs/pending-details.md`，commit 后停下等 Fable 评审；收到"继续"后再写规则、fixture、测试。

## 要做的

### A. 契约（§15，第一个 commit）

- 字段：只加一个取值——`ImmigrationEpisode.dependantOf` 增加 `'RELATIVE'`（HK BN(O) adult dependant relative：主申请人是此人的子女 / 孙子女 / 兄弟姐妹 / 父母，HK 59.1）。不加别的字段；年龄从 `dateOfBirth` 算；"最近一次许可为 dependent child / partner"从当前片段的 `role` + `dependantOf` 推；主申请人已定居用现有 `principal.settled`（同 SW 39.1(b) 的做法）；"在英国出生的子女"（GT 27.2(b)、SETF 10.3）不建模，写假设。
- 三组候选路径（都要求当前片段 `role = 'DEPENDANT'`，`CL-SCOPE` 相应改为 `PASS`）：
  1. **HK BN(O)**（当前片段 `HONG_KONG_BNO` + `DEPENDANT`）：
     - 申请日未满 18 岁、`dependantOf = 'PARENT'`：HK 57.2–57.3 + HK 58.1；没有 5 年要求（HK 62.1(b)）；英语免（EL 1.1(b)）、KOL 免（HK 61.1）；定居时点 = 主申请人现行法律栏的时点（同时获批），主申请人已在 HK 路线定居则为申请日。需要 `principal`；缺省 → `UNKNOWN`（同 `CL-SW-CHILD` 的写法）。父母是英国公民的情形不另建模（按 `principal.settled` 处理，解释里提一句 HK 57.3(b)）。
     - 18 岁以上（`PARTNER`，或已成年的 `PARENT`）：HK 62.1 + HK 63.1 按本人时间线算 5 年（dependant 许可本身就是可定居路线的许可），HK 60.1 B1、HK 61.1 KOL；快照里定居阶段对伴侣没有关系要求，所以**不需要 `principal`**，时点只看本人。
     - `RELATIVE`：HK 59.1（主申请人同时获批定居，或已定居 / 英国公民）+ HK 62.1 本人 5 年 + HK 60.1（65 岁以上免，EL 1.1(a)）+ HK 61.1（65 岁以上免）；时点 = max(本人 5 年, 主申请人时点)；需要 `principal`。
  2. **Global Talent**（当前片段 `GLOBAL_TALENT` + `DEPENDANT`，需要 `principal`，主申请人须是 `GLOBAL_TALENT` + `MAIN` 或已以该路线定居）：
     - `PARTNER`：GT 27.1–27.2 + GT 30.1（作为 P 的 dependent partner 连续 5 年，与主申请人是 3 年还是 5 年无关）+ GT 31.1 + GT 32.1 + GT 33.1；时点 = max(本人 5 年, 主申请人时点)。结构同 `CL-SW-PARTNER-5Y`。
     - `PARENT`：GT 27.1–27.3 + GT 29A.1（CHI 1.1–1.2、1A.1、2.1 按满足假设，解释里写）；没有合格期；GT 32.1（未满 18 免）、GT 33.1（18 岁以上）；时点 = 主申请人时点。
  3. **家庭伴侣的子女**（当前片段 `FAMILY_PARTNER_OR_PARENT` + `DEPENDANT` + `dependantOf = 'PARENT'`，需要 `principal`，主申请人为 `FAMILY_PARTNER_OR_PARENT` + `MAIN`）：
     - 主申请人 `familyPermission = 'PARTNER_TEN_YEAR'`：SETF 10.3 + 12.1 + 13.1–13.2 + 14.1 + 15.1 + 16.1；没有自己的合格期（随 P 同时获批，或 P 已定居）；时点 = 主申请人时点。SETF 11.3–11.6 的 10 年例外、12.2 另一位父母按满足假设。
     - `PARTNER_FIVE_YEAR`：D-LTRC.1.1 末句指向 Part 8 第 298 段，来源未登记 → 规则 `UNKNOWN` + 新 PD（"5 年路线伴侣的子女定居依据为 Part 8 para 298，待登记来源"），不给年限与日期。
     - `PARENT` 或缺省：`UNKNOWN`（同主申请人的处理）。
- 年限 / 起点：18 岁以上 HK、HK RELATIVE、GT PARTNER = 5；"随主申请人"的子女 = 主申请人现行法律栏的 `pathwayYears`（同 `CL-SW-CHILD` 的做法）。投影到 2027-03-26 之后须 B2 的假设对 GT / SETF 照加（HK 不加）。
- 短路、`principal` 缺省时的解释、`CL-ENGLISH` / `CL-KOL` 的年龄豁免：沿用 §8 / 5.2 的机制，只补来源段号。
- 不做：保护类、UK Ancestry、Innovator Founder、Private Life 的 dependant（维持 `UNKNOWN`）；Earned Settlement 栏；问卷（`'RELATIVE'` 选项与范围文案由 astra 在 5.5b 做）。
