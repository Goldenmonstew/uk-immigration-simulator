## A. 依赖与素材

- `apps/web` 加 `phaser@^3.90`（锁文件随之变动，列进 commit 清单）；`/game` 页面用 `next/dynamic(..., { ssr: false })` 只在客户端加载游戏组件，其他路由不引入 Phaser。
- 素材（CC0）放 `apps/web/public/game/assets/`，附 `ATTRIBUTION.md`（来源 URL、作者、许可、取用的文件清单）：
  - `sparklinlabs/superpowers-asset-packs` 的 `ninja-adventure`（GitHub raw：`https://raw.githubusercontent.com/sparklinlabs/superpowers-asset-packs/master/ninja-adventure/...`）：`background-elements/tileset.png`（地面、路、树、房子）、`characters/<n>.png`（四向行走）、`hud/` 需要的图标、可选 `musics/`。
  - 备选 / 补充：OpenGameArt "Zelda-like tilesets and sprites"（ArMM1998，CC0）`https://opengameart.org/sites/default/files/gfx_3.zip`。
  - 两个包都取不到时，用程序画的色块瓦片与简笔角色先把流程跑通，并在报告里说明；不要用非 CC0 素材。
- 建筑用招牌或图标标明用途（中英），不追求英国风。

## B. 场景（`apps/web/app/game/scene.ts` 等）

- 地图：Tiled JSON（`public/game/town.json`），约 32×22 格、16×16 瓦片：地面层、装饰层、碰撞层、建筑触发区（八个 `LocationId`：home、work、college、gp、pub、council、visa、station）。手写或用脚本生成都可，脚本不入仓库。
- 角色：四向行走动画；键盘方向键 / WASD；手机点按目标格子，网格 BFS 寻路走过去。相机跟随，地图边界夹紧。
- 走到建筑触发区：暂停移动，打开覆盖层的地点菜单。
- 季节：根据 `state.quarter` 给地面层换色调（春绿、夏亮、秋黄、冬白），冬季可加雪花粒子（可选）。
- 画布自适应：桌面 960×640 左右，手机横竖都能看全地图或可滚动；保持像素清晰（`pixelArt: true`）。

## C. 覆盖层（React，沿用 i18n；`apps/web/app/game/*.tsx`）

- 顶栏：角色名、第 N 年第 M 季与日期、剩余行动点、签证倒计时（`visaMonthsLeft`，≤ 6 个月变红）、五条属性条（钱以 £ 显示）。
- 进度条两条："现行法律 / 改革后"，由 `progress(state)` 的 `percent` 与 `outcome` 决定长度与颜色；点开显示该栏结论、年限、最早日期与"去市政厅看详情"。
- 地点菜单：`actions(state)` 过滤到当前地点的行动，显示费用与效果提示；市政厅菜单直接显示两栏完整评估（复用结果页的规则渲染，含"为什么"与来源）。
- 事件卡：`currentEvent(state)` 存在时弹出模态（标题、正文、2–3 个选择、`note` 小字），选择后显示属性变化（±）；有时间线变化时提示"进度条会在季末反应"。
- 季末小结：行动点用完或点"结束这一季"→ `endQuarter`，弹出小结（收入、开销、属性变化、签证倒计时、进度条变化、本季事件回顾）。
- 结局页：`isOver(state)` → 叙事（`narrative`）、两栏最终结果、成就、"在模拟器里打开这条时间线"（复用 v1 的 `gameDraft` / `encodeDraft`）、再玩一次、换角色。
- 角色选择：`characters` 列表（名字、简介、立绘用 `sprite` 的第一帧放大）；"继续上次"读取存档。
- 存档：`uk-immigration-life-v2:<characterId>`；每次状态变化写入；语言切换只换文字（`state.locale` 改掉并重算 `result`，同 v1 `withGameLocale`）。
- 删除 v1 的卡牌页组件、`uk-immigration-game-v1` 存档读取与相关测试；首页入口文案改为"玩一局 · Immigration Life"不变。
- `apps/web/lib/sources.ts` 加 SRC-030（及 sol 若登记了 SRC-031）的 URL 行；URL 见 sol 的报告或 `docs/SOURCES.md`（8.1 合并后再加也可）。
