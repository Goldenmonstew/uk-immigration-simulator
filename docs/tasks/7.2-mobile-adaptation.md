# 任务 7.2：全站移动端适配（负责：astra；Fable 验收）

## 背景

5.8 已确认 375px 下各页无横向溢出，但用户反馈手机上的阅读体验不好。Fable 2026-11-05 用内置浏览器按 375×812 走了一遍（main 当前构建），问题清单见 A 节；本任务按清单修，并把 390 / 414 两档一并核对。不重做视觉、不加依赖、不改引擎；中英同步；桌面布局不回归。

## 必读

- `AGENTS.md`；`docs/tasks/phase-7-plan.md` §2 的 7.2；`apps/web/app/site.module.css`（header、`.headerInner`、`@media` 断点）、`apps/web/components/site-shell.tsx`（header 与 `site.englishName`）、`apps/web/app/result/*`、`apps/web/components/result-view.tsx`（`AssessmentColumns`）、`apps/web/app/policy/*`、`apps/web/app/simulate/*`、`apps/web/i18n/routes.ts`（`routeLabel`）。

## A. Fable 审计发现（375×812，按严重度）

1. **header 占 221px**（屏高 27%）：站名、"政策依据 · Policy"、"方法说明 · About"各占一行（33px），语言切换两个按钮 48px 高，每页首屏都被挤掉三分之一。目标：窄屏 header 不超过 110px——第一行站名 + 右侧小号语言切换（两个按钮并排、高度约 36px、触控区仍 ≥ 44px 可用 padding 补）；第二行两个导航链接并排；删掉 `site.englishName` 副标题的 `<span>`、i18n 键与相关 CSS（桌面也删）。
2. **结果页太长**：文档高 10,211px，"已公布改革"栏从 4,248px 处才开始；两栏堆叠后没有任何导航；来源标签 105 个全部展开；"为什么"的三组（未满足 / 未知 / 已满足）只有 2 个 `details`。做法：窄屏在"你的路径模拟"标题下加两个锚点或切换（现行法律 / 已公布改革），并在每栏顶部给"跳到另一栏"；"已满足"组默认折叠（`details`），"未满足"与"未知"默认展开；每条规则的来源标签放进"来源（n）"折叠，或缩成一行小字；差距摘要保持在栏顶。打印样式不受影响（打印时全部展开）。
3. **/policy 页 33,899px**：参数清单每项一个块，等宽参数名在 375 下按字符断行（如 `longResidenceSettlementEnglishBefo re`）。做法：参数名允许 `overflow-wrap: anywhere` 且字号略小；按规则集 / 分组用 `details` 折叠（默认折叠，标题带条数）；两个表格（335px 宽，无溢出）保持，但外层加横向滚动容器以防将来加列。
4. **字号偏大**：窄屏 body 18px、h1 32px、h2 24px；标题"了解可能适用的移民路径"折成两行。做法：≤ 480px 时 body 16–17px、h1 26–28px、h2 20–22px、段落行距相应收紧；首页范围段落（很长）放进"建模范围"折叠，默认收起。
5. **问卷**：路线下拉在 375 下截断（"香港英国国民（海外）· Hong Ko"）。中文模式下窄屏只显示中文名（`routeLabel` 在窄屏去掉 "· English" 后缀，或 `<option>` 用短名），英文模式不变。输入字号 18px / 高 52px、按钮 54px 已达标，不动。
6. **What-if**：本次只在短路情景下看过（页面很短）。请用 Skilled Worker 的正常情景核对 390 宽下英语下拉、收入改写、日期控件的宽度与间距，必要时控件撑满一行。
7. **/about**、首页"本机保存的情景"、页脚：可接受，不动；只跟随 1 与 4 的全局改动。

## B. 做法与约束

- 断点：现有 `@media (max-width: …)` 的值沿用，新增规则放同一处；用 CSS 解决为主，少改组件结构；折叠一律用原生 `details` / `summary`。
- 只改 `apps/web/**`；零新依赖；中英同步；分享链接、打印样式、PWA 不受影响；测试按需要（如 `details` 默认开合、`site.englishName` 删除后的快照）。
- 报告 §1 附 375 / 390 / 414 三档的最终高度（header、首页、结果页、/policy）与修改前对比。

## 验收（Fable）

- gate 全过；内置浏览器 375 与 390：header ≤ 110px；结果页两栏可切换 / 跳转、"已满足"默认折叠、来源折叠；/policy 折叠后首屏可读；字号缩小后中英文无溢出；问卷路线下拉不截断；桌面（1120 宽）各页无回归；打印预览两栏仍全部展开。
