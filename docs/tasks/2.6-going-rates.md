# 任务 2.6：going rate 数据表（负责：sol；Fable 验收）

## 目标

现行法律下 Skilled Worker 定居薪资要求是"一般门槛 £41,700 与该职业 going rate 取高"（SRC-004 SW 24.3 row A），引擎现在只查一般门槛。本任务把 Immigration Rules Appendix Skilled Occupations 登记为来源并把 going rate 表机械提取到 `packages/policy-data`，供 Opus 在 2.5 实现 `CL-SW-GOING-RATE` 与 SW 24.3 rows B–E。你只做数据，不写规则。

- `docs/SOURCES.md`：一级来源表的列格式、`policy-sources/` 快照命名（`<版本日期>-<slug>.html`）、sha256 记法、"常用定位"写法；SRC-004 行下关于"页面头部 Updated 日期是整本手册的更新日，不是本 Appendix 版本日"的提醒。
- `packages/policy-data/src/data/public-funds-benefits.ts`、`occupations.ts`（数据表的写法与 `SourceRef`）、`packages/policy-data/test/sources.test.ts`。

## A. 来源登记（SRC-017）

- 抓取 `https://www.gov.uk/guidance/immigration-rules/immigration-rules-appendix-skilled-occupations` 的 HTML 到 `policy-sources/<版本日期>-immigration-rules-appendix-skilled-occupations.html`；版本日期取该 Appendix 自己的 gov.uk 变更记录最近一条（页面底部 "See all updates" / 变更记录），不是手册头部的 "Updated: 29 October 2026"。
- `docs/SOURCES.md` 表末尾加 SRC-017 行（等级 LAW），并在文件末尾加一节"SRC-017 常用定位"：各表的编号与用途（Table 1 中位数 going rate；Table 1a 2025-07-22 前获批者的附加职业；Table 2 25 百分位；Table 2aa / 2a / 2b 附加职业；Table 3 国家薪级的医疗 / 教育职业，薪级见 Table 4 / 5；Table 6 不合资格职业）。**只在文件末尾追加**，不要改动已有行（Opus 正在并行改 SRC-004 行）。

## B. 数据表与脚本

- `packages/policy-data/scripts/extract-skilled-occupations.mjs`：读取快照 HTML，输出 `packages/policy-data/src/data/skilled-occupations.ts`。脚本只做解析与生成，不联网；用 Node 内置模块，不加依赖。
- 生成文件导出（从 `src/index.ts` 导出）：

```ts
export interface GoingRate {
  socCode: string;          // 4 位 SOC 2020
  title: string;            // 表中职业名
  /** 年 going rate（GBP，按表中标注的工时基准），整数 */
  goingRate: number;
  table: '1' | '1a' | '2' | '2aa' | '2a' | '2b';
}
export const goingRates: { source: SourceRef; rows: GoingRate[] };
/** Table 3：going rate 按国家薪级（Table 4 / 5）确定的职业，只收代码与名称 */
export const nationalPayScaleOccupations: { source: SourceRef; rows: { socCode: string; title: string }[] };
```

- 一行有多个 going rate 列（如按不同工时或日期）时，取表头标注为年 going rate 的那一列；表头含义写进生成文件顶部注释。表里没有金额、只写"见 Table 4 / 5"的行归 Table 3 处理。
- 不提取 Table 4 / 5 的薪级明细、Table 6 不合资格清单；在 SOURCES.md 定位里说明它们存在。
- 测试（`packages/policy-data/test/skilled-occupations.test.ts`）：每张表的行数与快照里 `<table>` 的数据行数一致；抽查 3 行（如 2136、2231、3111，取表里真实存在的）代码、名称、金额与快照一致；`socCode` 都是 4 位数字且同一张表内不重复。现有 `sources.test.ts` 会递归检查新导出的 `SourceRef`。
